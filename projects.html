Case Studies & Projects

A selection of data architectures, risk management solutions, and AI integrations applied to high-stakes environments.

🏥 EpiData-Shield

Python / HPC / SIRD

🎯 The Challenge

During the COVID-Pro project, epidemiological data came from heterogeneous regional sources with non-standardized formats. The risk was introducing statistical bias into national reports due to inconsistencies and duplicates.

⚙️ The Architecture

I designed a Python ETL pipeline for real-time validation. I utilized the HPC infrastructure (INDACO) to process large volumes and implemented a time-dependent SIRD model for predictive analysis of viral spread.

🏆 Key Result

Scientific publication in IJERPH (Impact Factor 4.6). Validation protocols reduced anomalous data, ensuring scientific reproducibility during a crisis.

📊 RiskFlow-Engine

Python / R Shiny / FINMA

🎯 The Challenge

At Intesa Sanpaolo (Geneva), the regulatory reporting cycle (stress testing, IRRBB, LCR/NSFR) required days of manual work in Excel/VBA. This prevented risk managers from focusing on strategic analysis.

⚙️ The Architecture

I engineered an end-to-end pipeline (Python, R, SQL) to automate reporting. I also built an in-house Incident Management Tool using R Shiny and Posit Connect, eliminating the need for costly external procurement.

📈 Key Result

Reduced processing time from days to hours. The internal tool was adopted by over 300 employees, cutting incident follow-up times from days to 30 minutes.

🤖 Agentic-DocExtract

LangChain / LLM / FINMA

🎯 The Challenge

Drafting regulatory documentation for FINMA/ECB scenarios requires hours of manual work to ensure terminological consistency and regulatory alignment.

⚙️ The Architecture

I integrated an LLM layer (LangChain + Python) into the reporting workflow. I implemented a RAG (Retrieval-Augmented Generation) system with ChromaDB to query regulatory documents and automatically extract relevant clauses.

🤖 Key Result

Automated generation of narrative commentary with guaranteed traceability (Human-in-the-loop). Drastic reduction in drafting time and elimination of terminological errors.

🛡️ Finnova -> Prometeia Pipeline

SQL / Data Governance

🎯 The Challenge

Data integration from core banking (Finnova) to the ALM/Risk system (Prometeia ERMAS) lacked traceability, jeopardizing compliance with FINMA-required second-line controls.

⚙️ The Architecture

I redesigned the data lineage on PostgreSQL, implementing systematic validation controls. I created an automated reconciliation framework between front-office positions and regulatory aggregates.

🏅 Key Result

Automated reconciliation with an error margin of less than 0.01%, ensuring total data integrity and traceability for IRRBB and liquidity calculations.
