# 🚀 Portfolio Personale — Giuseppe | Data Engineer & Senior Risk Manager

Benvenuto nel repository del mio sito web personale e portfolio professionale. Questo progetto è stato progettato e sviluppato da zero per presentare le mie competenze nell'ambito della **Data Engineering, Risk Governance, Modellistica Quantitativa e Agentic AI**.

---

## 🛠️ Stack Tecnologico & Strumenti

Il sito è stato realizzato seguendo rigorose best practice di sviluppo front-end:
* **HTML5 Semantico**: Struttura delle pagine pulita e ottimizzata per l'accessibilità e la SEO.
* **Sass (SCSS)**: Architettura modulare dei fogli di stile tramite partials (`_variables`, `_mixins`, `_base`, ecc.) per una manutenibilità avanzata.
* **Bootstrap 5**: Utilizzato per il sistema di griglie responsive e componenti nativi.
* **Flexbox & CSS Grid**: Layout avanzati e moderni per la disposizione fluida dei contenuti.
* **EmailJS**: Integrazione per la gestione dei messaggi dal modulo di contatto senza esporre dati sensibili.
* **Git & GitHub Pages**: Controllo di versione e deployment continuo per la messa online del sito.
